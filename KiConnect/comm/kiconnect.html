Quick intro

A short orientation for setting up KI Connect and finding the most important controls.

1
Choose interface language
Start by choosing the language for KI Connect. The whole interface updates immediately.
2
Add an API provider
Open API, add a provider, enter a readable name, choose the provider type, add the server URL if needed, then paste the API key.
3
Choose a model
After saving the provider, use the model picker at the top to choose one of the loaded models.
4
Optional profile
Use Profile to create roles or personas with their own system prompt and output settings.
5
Organize chats
Use folders in the sidebar. Multi-select lets you select several chats and move or delete them together.
